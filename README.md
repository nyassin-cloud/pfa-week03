# pfa-week03
A2 — Next level
For A2, I took Route A and expanded my original falling snow tool. My A1 tool could only create falling snow using an uploaded image with basic controls for the amount, size, area, and speed. The new version is a full weather generator that can create snow, rain, ash, dust, leaves, storms, thunderstorms, fog, sandstorms, and other effects. The biggest new capability is that the weather can now interact with objects already in the Maya scene. Snow, ash, and dust can build up on surfaces, while rain can create splashes and growing puddles. I also added more control over the weather area, automatic scene fitting, different particle shapes, wind and turbulence settings.
